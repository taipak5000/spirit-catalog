# [精霊ツリー管理](https://taipak5000.github.io/tai-catalog/)

「Sky　星を紡ぐ子どもたち」の全精霊（216体）の精霊ツリーを、本家のような枝分かれ図で表示し、
ノードの解放状況を記録できるサイトです。ノードを解放すると、item（アイテム所持管理）の所持アイテム・
所持通貨、wings（羽トラッカー）の翼の光、emote（エモート所持率管理）の所持エモートにも自動で同期します。

## データソース

[SkyGame-Data](https://github.com/Silverfeelin/SkyGame-Data)（コミュニティが管理するオープンソースの
ゲームデータ。sky-planner.com（SkyGame-Planner）と同じデータソース）を元に、精霊名・アイテム名の
日本語訳を独自に付与しています（216体中213体、2,343アイテムノード中2,089件に日本語名あり）。

このサイトはSky 星を紡ぐ子どもたちの非公式ファンサイトです。thatgamecompanyは一切関与していません。
